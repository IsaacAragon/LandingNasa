# Salomonsters · Aresmap

**Aresmap** es el mapa para el primer paso en Marte: un visor por capas del cráter Gale con datos de Curiosity, MRO y la NASA para planear una caminata de astronautas desde Bradbury Landing hasta los boxwork de Mount Sharp.

Proyecto del equipo **Salomonsters** para el **NASA Space Apps Challenge**.

```bash
pnpm install
pnpm dev      # servidor de desarrollo
pnpm build    # build de producción con prerender (inglés y español)
```

Sitio: https://aresmap.dev (inglés en `/`, español en `/es/`).
